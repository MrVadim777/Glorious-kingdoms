# Glorious Kingdoms

> **v2.0 — Великая реконструкция**
>  
> Чистый, мощный и (наконец-то) понятный C++ проект на базе ECS-архитектуры.  
> Рожден из боли. Закален rebase’ом. Принесён в жертву .vs.

---

## ⚙️ Технологии

- C++17
- SFML (графика, окна, взаимодействие)
- Entity-Component-System (ECS)
- Ручная обработка событий (без костылей, почти)

🧩 Компоненты
Компоненты содержат данные, которые потом используют системы.
PositionComponent — координаты сущности.
SpeedComponent — скорость движения.
RenderableComponent — визуальные параметры (цвет, форма).
DirectionComponent — направление движения (вверх, вниз и т.д.)
PlayerTagComponent / NpcTagComponent — маркеры для фильтрации сущностей.
IComponent — базовый интерфейс. Почти абстрактный бог ECS.

⚙️ Системы
Системы отвечают за логику, используя нужные компоненты:
InputSystem — обрабатывает ввод с клавиатуры.
NpcAISystem — управляет NPC: глупые, но целеустремлённые.
MovementSystem — перемещает сущности на основе направления и скорости.
RenderSystem — рисует всё, что шевелится и не шевелится.

🧠 Ядро
Entity — сущность, контейнер для компонентов.
EntityManager — управляет созданием/удалением сущностей.
Game — главный цикл: инициализация, апдейт, рендер, повторить.

🛠️ Форматирование
Код форматируется автоматически по правилам .clang-format, основанным на стиле IntelliJ IDEA:
Отступы: 4 пробела
Скобки: Allman (на новой строке)
Лимит строки: 240 символов (на всякий случай)
Читаемость: максимальная, как предсмертная записка
